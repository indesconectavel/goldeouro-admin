🧹 Limpeza de Cache - Gol de Ouro Admin

Este script irá limpar o cache do navegador e forçar o reload da aplicação.

Clique no botão abaixo para limpar o cache

Instruções:

  1. Clique em "Limpar Cache e Recarregar"
  2. Aguarde a confirmação
  3. Clique em "Ir para Admin"
  4. Pressione Ctrl+F5 para forçar reload
